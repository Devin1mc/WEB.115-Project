# WEB-115 Final Project: Weekly Meal Planner

**Project Title:** Build Your Meal Plan  
**Student:** Devin McLoughlin  
**Course:** WEB-115  
**Section:** WEB-115-0006

## Project Overview:
This project is a JavaScript-based weekly meal planner web application designed for a fictional fitness company. The user-friendly interface allows users to input five daily meals (Breakfast, Snack, Lunch, Snack, Dinner) for each day of the week (Monday–Sunday). Users are also prompted to enter their personal information, including name, email, and weekly goal.

## Key Features:
- Clean and structured **HTML layout** with a professional banner.
- External **JavaScript file (`projectJS.js`)** handles logic and interactivity.
- **Email validation** ensures a valid email is entered before generating a plan.
- Users can **generate a custom meal plan** in a new window using `document.write()`.
- The generated page includes:
  - A printable version of the meal plan
  - A **downloadable .txt file** version of the plan
- **Clear form** functionality to reset all inputs.

## Technical Highlights:
- Use of **document.write()** to dynamically generate and display a new HTML document.
- Utilization of **monospaced formatting** and string padding for clean meal plan alignment.
- Implementation of **Blob API** for meal plan download functionality.
- Separation of structure (HTML) and behavior (JavaScript) following web development best practices.

This project demonstrates a solid understanding of HTML forms, DOM manipulation, JavaScript functions, basic validation, and dynamic page generation.
